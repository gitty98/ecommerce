# 🍰 Bakery Website

A responsive bakery and e-commerce showcase website built using HTML, CSS and JavaScript. This project features a modern product gallery, interactive navigation, an About Us section, a contact form and a customer showcase.

## 📸 Project Overview

The website provides a simple and visually appealing way to showcase bakery products and present information about a bakery business.

## ✨ Features

- **Navigation Bar:** Navigation links with a dropdown menu.
- **Welcome Banner:** A welcoming hero section with animated text.
- **Product Gallery:** Displays bakery products with hover effects and prices.
- **About Us:** Information section with progress indicators.
- **Contact Form:** A form for visitors to enter their name, email and message.
- **Customer Showcase:** Displays customer or bakery information.
- **Responsive Design:** Layout adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome 5

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/gitty98/ecommerce.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.
